# Sales Forecasting

## Overview

This project explores historical sales data and develops forecasting models to predict future sales trends. The analysis includes data cleaning, exploratory data analysis (EDA), feature engineering, model development, and evaluation of forecasting performance.

The goal is to identify patterns in historical sales behaviour and generate accurate sales predictions that could support business planning and decision making.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## How to Run

1. Clone or download this repository.
2. Install required packages:

```bash
pip install -r requirements.txt
```

3. Open the notebook:

```bash
jupyter notebook sales_forecasting.ipynb
```

4. Run all cells sequentially.
